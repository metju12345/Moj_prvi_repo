# Moj_prvi_repo

## Erinnerung gegen Gerichtskosten / Objection to Court Costs

Dieses Repository enthält Dokumente für die Einlegung einer Erinnerung gegen Gerichtskosten beim Bayerischen Landessozialgericht.

### Dokumente / Documents

1. **ANLEITUNG.md** - Vollständige Anleitung zur Verwendung der Dokumente
2. **Erinnerung_Gerichtskosten.txt** - Das fertige Schreiben (kopieren, Datum eintragen, unterschreiben, versenden)
3. **Rechtliche_Grundlagen.md** - Erklärung der rechtlichen Grundlagen

### Schnellstart / Quick Start

1. Öffnen Sie `ANLEITUNG.md` für detaillierte Anweisungen
2. Öffnen Sie `Erinnerung_Gerichtskosten.txt` für das fertige Schreiben
3. Tragen Sie das Datum ein
4. Drucken, unterschreiben und mit den erforderlichen Anlagen versenden
