# Moj_prvi_repo

Dobrodošli! Ovo je moj prvi testni repozitorij na GitHubu. Služi za učenje osnova verzioniranja koda i suradnje.

## Što je ovaj repozitorij?
- Jednostavno mjesto za vježbanje rada s GitHubom.
- Možete dodavati datoteke, mijenjati ih i pratiti promjene kroz vrijeme.
- Nema složenog koda – cilj je upoznati se s osnovnim pojmovima.

## Kako GitHub radi (ukratko)
- **Repozitorij**: mapa na internetu u kojoj živi vaš kod ili dokumenti.
- **Commit**: snimka promjene. Kad nešto uredite i spremite commit, lakše pratite povijest.
- **Branch (grana)**: paralelna linija razvoja. Možete sigurno isprobavati promjene bez utjecaja na glavnu verziju.
- **Pull Request (PR)**: zahtjev da se promjene iz grane spoje u glavnu granu. U PR-u drugi mogu pregledati vaš rad.
- **Issues**: kartice za prijavu zadataka, bugova ili ideja.

## Kako GitHub Copilot Agent može pomoći
- Odgovara na pitanja o repozitoriju i objašnjava što datoteke rade.
- Predlaže jednostavne promjene ili korake, npr. kako dodati novu datoteku ili napisati commit poruku.
- Pomaže pisati dokumentaciju (poput ovog README-a) ili komentare na jasnom i jednostavnom jeziku.

## Kako započeti
1. Napravite malu promjenu (npr. uredite tekst u README-u).
2. Spremite commit da zabilježite promjenu.
3. Otvorite Pull Request ako želite da netko pregleda i spoji vašu promjenu u glavnu granu.
